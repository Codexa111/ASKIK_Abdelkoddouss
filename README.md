# Portfolio — ASKIK ABDELKODDOUSS

Portfolio statique en HTML, CSS et JavaScript, prêt à publier sur GitHub Pages.

## Contenu
- `index.html` : site responsive avec animations et sections du CV.
- `assets/CV_Askik_Abdelkoddouss.pdf` : CV téléchargeable.
- La zone photo est un emplacement temporaire. Pour ajouter la vraie photo, placez une image sous `assets/photo.jpg`, puis remplacez dans `index.html` le bloc `<div class="photo-placeholder">...</div>` par :
  `<img src="assets/photo.jpg" alt="Photo de ASKIK ABDELKODDOUSS">`
  (gardez la balise à l'intérieur de `.photo-frame`).

## Publication sur GitHub Pages
1. Décompressez le ZIP.
2. Créez un dépôt GitHub, par exemple `askik-portfolio`.
3. Importez `index.html` et le dossier `assets`.
4. Ouvrez **Settings → Pages**.
5. Dans **Build and deployment**, choisissez **Deploy from a branch**, puis `main` et `/ (root)`.
6. Enregistrez et attendez que GitHub Pages fournisse l'URL du site.

## Personnalisation
- Les logiciels de CAO ne sont pas mentionnés car ils restent à confirmer.
- La section Projets présente les objectifs d'études et professionnels, pas de réalisations inventées.
- Le site utilise Google Fonts ; si la connexion est absente, des polices de remplacement sont utilisées.
- Vérifiez avant publication que vous souhaitez afficher publiquement le numéro de téléphone.
